# 站点介绍

MoluranliStudy 是我的个人学习笔记站，用 [docsify](https://docsify.js.org/) 搭建，托管在 GitHub Pages 上。

## 这里有什么

- **秋招准备**：Java 基础、集合、MySQL 索引、JVM、五大排序、面试题
- **中间件学习**：Redis、Shiro
- **常用设计模式**：模式说明 + 代码示例
- **项目学习**：在线论坛项目

## 技术栈

docsify + docsify-themeable（深色主题）。所有前端依赖都放在仓库的 `assets/` 目录里，不依赖外部 CDN。

## 更新方式

内容就是仓库里的 Markdown 文件，`git push` 到 `master` 后由 GitHub Actions 自动构建发布。

## 书写约定

- 每篇笔记以一级标题开头，正文用二级标题分节
- 代码块标注语言，方便高亮
